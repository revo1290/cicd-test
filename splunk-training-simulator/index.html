🎯 Splunkとは？

Splunkは、ログデータの収集、分析、可視化を行う運用監視ツールです。このシミュレーターでは、Splunkの基本的な機能を無料で学習できます。

📚 基本的なSPL（Search Processing Language）

1. 基本的な検索

source=web_access

特定のソースからすべてのログを取得します。

2. フィールドでフィルタリング

source=web_access status=500

特定のフィールド値でログをフィルタリングします。

3. 比較演算子

source=web_access status>=400

数値フィールドで比較演算子を使用します。

4. 統計コマンド (stats)

source=web_access | stats count by status

フィールドごとにイベント数を集計します。

5. 複数フィールドでの集計

source=web_access | stats count, avg(response_time) by host

複数の統計値を同時に計算します。

6. ソートコマンド

source=web_access | stats count by status | sort -count

結果を降順でソートします（-は降順、なしは昇順）。

💡 練習問題

問題1: エラーログの分析

アプリケーションログからERRORレベルのログを検索してください。

問題2: ホスト別のアクセス数

Webアクセスログをホスト別に集計し、アクセス数の多い順に並べてください。

問題3: 遅いリクエストの検出

レスポンスタイムが500ms以上のWebアクセスログを検索してください。
