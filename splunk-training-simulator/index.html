チュートリアル

🎯 Splunk Training Simulatorへようこそ

このシミュレーターでは、実際の運用環境で使用される様々なログフォーマットを使用して、Splunkの基本的な機能を学習できます。

  • Apache/Nginx: Webサーバーアクセスログ
  • Syslog: Linuxシステムログ
  • JSON: 構造化ログデータ
  • Database: データベースクエリログ
  • Security: セキュリティイベント
  • API Gateway: API呼び出しログ

📚 基本的なSPL（Search Processing Language）

1. ソースの指定

source=apache_access

特定のログソースからすべてのデータを取得します。

2. フィールドでフィルタリング

source=apache_access status=500

特定のフィールド値でログをフィルタリングします。

3. 比較演算子の使用

source=nginx_access request_time>=0.5

数値フィールドに対して比較演算子を使用できます。

4. 統計コマンド - count

source=security | stats count by severity

フィールドごとにイベント数を集計します。

5. 統計コマンド - avg

source=database | stats avg(duration_ms) by query_type

数値フィールドの平均値を計算します。

6. 複数の統計関数

source=api_gateway | stats count, avg(latency_ms), max(latency_ms) by endpoint

複数の統計値を同時に計算できます。

7. ソート

source=apache_access | stats count by clientip | sort -count

結果を降順（-）または昇順でソートします。

8. head コマンド

source=json_logs | stats count by country | sort -count | head 5

結果の最初のN件のみを表示します。

💡 実践的な練習問題

問題1: 高レイテンシーAPIの特定

API Gatewayログから、レイテンシが1000ms以上のエンドポイントを見つけ、エンドポイント別に集計してください。

問題2: セキュリティ脅威の分析

セキュリティログから、深刻度が「high」のイベントを抽出し、イベントタイプ別に集計してください。

問題3: データベースパフォーマンス分析

データベースログから、クエリタイプ別の平均実行時間を計算し、遅い順に並べてください。

問題4: 地理的アクセス分析

JSONログから、国別のアクセス数を集計し、トップ5を表示してください。

問題5: Webサーバーエラー分析

Apacheログから、4xx/5xxエラーのステータスコード別件数を集計してください。
